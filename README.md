# self-learning-java
A beginner learning Java on my own, doing basic exercises.

## 📌 仓库说明
- 学习目标：掌握Java基础语法、面向对象、常用API等
- 练习内容：基础语法题、小项目、算法练习

## 📂 目录结构
- `/basics`：基础语法练习（HelloWorld、变量、循环等）
- `/oop`：面向对象练习（类、继承、接口等）

## 🚀 如何运行
1.  确保已安装JDK 8+
2.  进入对应目录，执行 `javac 文件名.java` 编译
3.  执行 `java 类名` 运行程序
